# ✨ 功能特性详解

## 🎨 多主题阅读系统

### 9 种精心设计的主题

#### 1. 📄 Medium 经典
- **设计灵感**: Medium 官方设计
- **适用场景**: 专业文章、技术博客
- **特点**: 纯白背景、绿色强调、最大化可读性
- **推荐时间**: 全天候

#### 2. 🌿 护眼纸张
- **设计灵感**: 纸质书籍
- **适用场景**: 长时间阅读、小说
- **特点**: 米黄背景、降低对比度、减轻眼疲劳
- **推荐时间**: 下午 12:00-18:00

#### 3. 🌙 深夜模式
- **设计灵感**: OLED 深色模式
- **适用场景**: 夜间阅读、暗光环境
- **特点**: 真黑背景、省电护眼、高对比度
- **推荐时间**: 晚上 22:00-6:00

#### 4. 📖 Kindle 风格
- **设计灵感**: Amazon Kindle
- **适用场景**: 电子书、经典文学
- **特点**: 低对比度、温暖色调、专注体验
- **推荐时间**: 下午-傍晚

#### 5. 🍎 Apple Books
- **设计灵感**: iOS Apple Books
- **适用场景**: 现代阅读、短篇文章
- **特点**: 极简设计、系统蓝色、精致细节
- **推荐时间**: 全天候

#### 6. 🌸 微信读书
- **设计灵感**: 微信读书 App
- **适用场景**: 移动阅读、中文内容
- **特点**: 护眼米黄、橙色强调、中文优化
- **推荐时间**: 碎片化阅读

#### 7. 🌊 柔和渐变
- **设计灵感**: 现代 UI 设计
- **适用场景**: 诗歌、散文、创意内容
- **特点**: 紫色渐变、毛玻璃效果、优雅氛围
- **推荐时间**: 轻松阅读

#### 8. 🌌 深空模式
- **设计灵感**: 科幻美学
- **适用场景**: 技术文档、科幻小说
- **特点**: 深蓝渐变、文字发光、沉浸体验
- **推荐时间**: 夜间深度阅读

#### 9. 🌅 暖阳模式
- **设计灵感**: 日出氛围
- **适用场景**: 早晨阅读、温暖内容
- **特点**: 温暖渐变、橙色强调、舒适氛围
- **推荐时间**: 早晨 6:00-12:00

### 主题特性

- ✅ **自动保存**: 选择的主题自动保存到本地
- ✅ **平滑过渡**: 0.5s 的优雅切换动画
- ✅ **响应式**: 所有主题适配移动端
- ✅ **可访问性**: 满足 WCAG AA 对比度标准

## 📚 多源内容聚合

### 书籍模块

#### Open Library
- **数据量**: 数百万书籍
- **功能**: 搜索、封面、详情
- **特点**: 无需 API Key、完全免费

#### Gutendex
- **数据量**: 70,000+ 公版书
- **功能**: 在线阅读完整书籍
- **特点**: 可直接阅读文本、支持多语言

#### 多源搜索
- 同时搜索 Open Library 和 Gutendex
- 智能合并结果
- 优先显示可阅读书籍

### 新闻模块

#### RSS 新闻
- **支持源**: BBC、NYT、人民网等
- **功能**: 实时新闻、相对时间显示
- **特点**: 可自定义 RSS 源

#### Hacker News
- **数据源**: Hacker News API
- **功能**: 科技新闻热榜、评论数
- **特点**: 实时更新、直接跳转原文

### 知识模块

#### 维基百科
- **数据源**: 中文维基百科 API
- **功能**: 搜索、摘要、完整词条
- **特点**: 支持图片、快速预览

### 网页阅读器

#### Mozilla Readability
- **技术**: 官方 Readability.js
- **功能**: 智能提取正文、移除广告
- **特点**: 
  - 自动识别文章标题
  - 提取作者信息
  - 计算阅读时间
  - 保留图片和格式

#### CORS 代理
- **服务**: AllOrigins
- **功能**: 跨域访问任意网页
- **特点**: 免费、无限制

### 本地阅读

#### 功能
- 保存文章到 localStorage
- 显示保存时间
- 一键清空
- 离线访问

## 🎯 阅读器功能

### 字体调节
- **范围**: 14px - 32px
- **步进**: 2px
- **实时预览**: 即时生效
- **Toast 提示**: 显示当前字号

### 行距调节
- **范围**: 1.2 - 2.5
- **步进**: 0.1
- **实时预览**: 即时生效

- **功能**: 返回列表页

## 🔧 技术特性

### 纯前端
- **无后端**: 完全静态
- **无数据库**: localStorage 存储
- **无服务器**: 可部署到 CDN

### 无需 API Key
- **所有 API**: 完全免费
- **无限制**: 无请求限制（部分有限流）
- **无注册**: 无需账号

### 跨域支持
- **CORS 代理**: AllOrigins
- **备选方案**: 直接打开原网页
- **兼容性**: 支持所有现代浏览器

### 性能优化
- **防抖**: 搜索防抖
- **节流**: 滚动节流
- **懒加载**: 按需加载内容
- **缓存**: localStorage 缓存

### 可访问性
- **对比度**: WCAG AA 标准
- **语义化**: 正确的 HTML 标签
- **键盘**: 支持键盘导航
- **屏幕阅读器**: 友好的标签
