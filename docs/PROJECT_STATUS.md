## 🐛 已知问题

### 轻微问题
1. **CORS 限制**
   - 某些网站无法解析
   - 解决方案：使用代理或直接打开

2. **API 限流**
   - RSS2JSON 可能限流
   - 解决方案：等待或切换源

3. **字体加载**
   - Charter 字体可能不可用
   - 解决方案：自动降级到 Georgia

### 待优化
1. 搜索结果缓存
2. 图片懒加载
3. 更多快捷键
4. 更好的错误提示
