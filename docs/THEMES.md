# 🎨 阅读主题指南

PureReader 提供 9 种精心设计的阅读主题，每种主题都针对不同的阅读场景和个人偏好进行了优化。

## 主题切换

### 如何切换主题
1. 点击右上角的 🎨 图标
2. 在弹出的主题选择器中选择喜欢的主题
3. 主题会自动保存，下次访问时自动应用

### 主题特性

#### 自动保存
- 选择的主题会保存到浏览器 localStorage
- 下次访问自动恢复上次的主题

#### 平滑过渡
- 所有主题切换都有 0.5s 的平滑过渡动画
- 背景、文字、边框颜色同步变化

#### 响应式优化
- 所有主题都针对移动端优化
- 自动适配不同屏幕尺寸

## 自定义主题

想要创建自己的主题？编辑 `style.css` 文件：

```css
/* 你的自定义主题 */
body.theme-custom {
    --bg: #你的背景色;
    --text: #你的文字色;
    --text-secondary: #你的次要文字色;
    --border: #你的边框色;
    --card-hover: #你的悬停色;
    --accent: #你的强调色;
    --accent-hover: #你的强调悬停色;
}
```

然后在 `script.js` 中添加主题选项：

```javascript
const themes = {
    // ... 其他主题
    custom: { name: '我的主题', icon: '✨' }
};
```

## 技术细节

### CSS 变量系统
所有主题都使用 CSS 自定义属性（变量）实现，确保：
- 一致的设计语言
- 易于维护和扩展
- 平滑的主题切换

### 性能优化
- 使用 CSS 变量避免重复样式
- 过渡动画使用 GPU 加速
- 渐变背景使用 `background-attachment: fixed`

### 可访问性
- 所有主题都满足 WCAG AA 对比度标准
- 深色主题使用真黑背景节省电量
- 文字大小和行距可自定义

## 常见问题

### Q: 主题会在不同设备间同步吗？
A: 不会。主题保存在浏览器的 localStorage 中，不同设备需要分别设置。

### Q: 可以设置自动切换主题吗？
A: 目前不支持，但你可以根据时间手动切换推荐的主题。

### Q: 为什么有些主题看起来很相似？
A: 每个主题都有细微的差异，包括背景色、文字色、强调色和排版参数，选择最适合你的即可。

### Q: 可以导出/导入主题设置吗？
A: 目前不支持，但主题设置会自动保存在浏览器中。

## 🛠️ 自定义主题

想要创建自己的主题？编辑 `assets/css/style.css` 文件：

```css
/* 你的自定义主题 */
body.theme-custom {
    --bg: #你的背景色;
    --text: #你的文字色;
    --text-secondary: #你的次要文字色;
    --border: #你的边框色;
    --card-hover: #你的悬停色;
    --accent: #你的强调色;
    --accent-hover: #你的强调悬停色;
}
```

然后在 `assets/js/script.js` 中添加主题选项：

```javascript
const themes = {
    // ... 其他主题
    custom: { name: '我的主题', icon: '✨' }
};
```

最后在 `index.html` 中添加选项：

```html
<div class="theme-option" data-theme="custom">
    <span>✨</span> 我的主题
</div>
```
